# Мониторинг питания (PWA)

Загружаете PDF-отчёты «Мониторинг питания» (по одному, несколько сразу или ZIP-архив с PDF) —
приложение собирает Excel-файл в формате «Мониторинг востребованности питания».
Всё работает в браузере, файлы никуда не отправляются; после первого открытия приложение работает офлайн.

## Откуда берутся данные

| Столбец Excel | Источник в PDF |
|---|---|
| Дата | Дата вылета |
| № рейса | Рейс № (выводится как `SU1212`) |
| Направление | справочник «рейс → город» (из образца), иначе по коду аэропорта |
| Загружено пит | Количество загруженных порций питания согласно накладной |
| Кол-во PAX | Фактическое количество пассажиров |
| Остаток | Количество порций невостребованного питания |
| Комментарии | Замечания, комментарии (если не «-») |

Столбцы «Перегруз», «Не востребовано (от PAX / от порций)» — формулы, как в образце.
Строки без данных или с 0 загруженных порций подсвечиваются жёлтым.

Если город исправить вручную, приложение запомнит его для этого номера рейса (хранится в браузере).
Справочник по умолчанию — `cities.js`.

## Запуск

Нужен любой статический HTTPS-хостинг (например, GitHub Pages: опубликовать папку `meal-report-pwa`).
Локально: `python3 -m http.server -d meal-report-pwa 8000` и открыть http://localhost:8000.
В Chrome/Edge/Android — «Установить», в iOS Safari — «Поделиться → На экран Домой».

## Ограничения

* PDF должен иметь текстовый слой (сканы не распознаются).
* Архивы — только ZIP (вложенные ZIP поддерживаются).
* Если в отчёте несколько классов обслуживания, берётся «Эконом» (с предупреждением).

Сторонние библиотеки (лежат в `vendor/`): pdf.js 4.10.38, ExcelJS 4.4.0, JSZip 3.10.1.
