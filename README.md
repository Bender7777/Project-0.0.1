# Дашборд голосования (PWA)

Прогрессивное веб-приложение для анализа списков голосования. Работает полностью
в браузере: Excel-файл не отправляется на сервер, вся обработка — на клиенте.

## Возможности

- Загрузка `.xlsx` / `.xls` / `.csv` кнопкой или перетаскиванием файла.
- Дашборд со статистикой:
  - Общее число сотрудников по отделам.
  - Число и доля сотрудников в декретном отпуске (ДО) и без.
  - Явка по дням (18, 19, 20 сентября) — число, процент, график.
  - Сколько сотрудников из ДО проголосовало — число и процент.
  - Способ голосования (ДЭГ / очно) среди проголосовавших из ДО.
  - Сколько всего не проголосовало — отдельно ДО и ЧКЭ.
  - Дополнительно: общий способ голосования, явка по отделам, нагрузка и
    явка по инструкторам, разбивка «день × способ голосования».
- Фильтр по отделам (выпадающий список с чекбоксами над дашбордом) — все
  графики, таблицы и KPI пересчитываются на лету по выбранным отделам.
- Переключатель категории «Все / ЧКЭ / ДО» рядом с фильтром отделов — сужает
  весь дашборд до сотрудников в декретном отпуске или без него; сочетается
  с фильтром по отделам.
- Клик по столбцу «По отделам» фильтрует весь дашборд по этому отделу (тот
  же фильтр, что и в выпадающем списке выше) — повторный клик по
  единственному выбранному отделу возвращает все отделы.
- Клик по столбцу, сегменту графика (кроме «По отделам») или по самой
  KPI-плитке наверху открывает окно со списком конкретных сотрудников,
  попавших в эту величину, и кнопкой выгрузки этого списка в отдельный
  Excel-файл.
- Установка как приложение (PWA): офлайн-доступ к оболочке приложения и к
  последнему загруженному набору данных (хранится локально в браузере).
- Переключение светлой/тёмной темы. Оформление в цветах российского флага
  (бело-сине-красная полоса, синий/красный акценты) с объёмным стилем —
  градиенты, многослойные тени, приподнимание карточек и кнопок при наведении.

## Запуск

Статические файлы, сборка не требуется. Откройте `index.html` через любой
статический HTTP-сервер, например:

```bash
python3 -m http.server 8080
# затем откройте http://localhost:8080
```

Service worker требует HTTPS или `localhost`.

### Однофайловая версия

`voting-dashboard.html` — та же самая программа, полностью упакованная в один
HTML-файл (стили, парсер, статистика, графики, библиотеки xlsx.js и Chart.js
и иконки инлайнены). Её можно открыть двойным кликом прямо с диска, без
сервера — удобно для передачи одним файлом. Из-за ограничений браузеров
service worker в этот файл не встроен, поэтому оффлайн-кэш оболочки
приложения (в отличие от многофайловой версии) не работает — но сама
статистика и последний загруженный файл по-прежнему сохраняются в
`localStorage` браузера.

## Формат Excel-файла

Первая строка — заголовки, порядок колонок не важен, лишние колонки
игнорируются. Ожидаемые заголовки:

`Отдел`, `Фамилия, Имя, Отчество`, `Таб.№`, `SAP таб`, `Декрет`, `Инструктор`,
`Факт выполнения`, `ДАТА`, `ДЭГ/ОЧНО`.

## Структура проекта

```
index.html            разметка приложения
manifest.webmanifest   PWA-манифест
sw.js                   service worker (кэш оболочки приложения)
src/style.css           стили
src/palette.js          цветовая палитра (свет/тёмная тема)
src/parser.js           разбор Excel-файла (SheetJS)
src/stats.js            расчёт статистики
src/charts.js           рендер графиков (Chart.js) и таблиц
src/app.js              логика приложения, PWA, тема, хранение данных
vendor/                 локальные копии xlsx.js и Chart.js (офлайн-режим)
icons/                  иконки PWA
```
