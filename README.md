# ОУКП — Реестр сотрудников

Офлайн-приложение для отдела управления квалификацией персонала (ОУКП) департамента обслуживания на борту.

## Запуск

Открыть `oukp.html` двойным кликом в любом современном браузере. Интернет нужен только для загрузки CDN-библиотек (SheetJS, JSZip, шрифты) — при их отсутствии часть функций (экспорт в Excel, генерация `.docx`) будет недоступна, но реестр и редактирование работают офлайн.

## Структура репозитория

| Путь | Назначение |
|------|-----------|
| `oukp.html` | Готовое приложение (единый файл). |
| `ДОКУМЕНТАЦИЯ.md` | Полное описание проекта: модель данных, справочник функций, план разработки. |
| `source/Рисунок.png` | Логотип «Аэрофлот», встроенный в `oukp.html` (шапка Листа ознакомления). |
| `assets/oukp-emblem.png` | Эмблема ОУКП (доп. ассет проекта). |

Подробности — в [`ДОКУМЕНТАЦИЯ.md`](./ДОКУМЕНТАЦИЯ.md), включая план поэтапного рефакторинга в модульную структуру.
